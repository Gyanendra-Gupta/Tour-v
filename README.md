# 🌍 Tour-v – Responsive Travel Agency Website

**Tour-v** is a responsive and modern travel agency website built using **HTML**, **CSS**, **Bootstrap**, and **JavaScript**. This is a fully frontend-based project designed to showcase web design and UI/UX skills, perfect for portfolio and frontend development practice.

---

## ✨ Features

- 🧭 Multi-page website (Home, Destinations, Packages, About, Contact)
- 📱 Fully responsive layout using Bootstrap
- 🔽 Dropdown navigation bar
- 💡 Clean and modern UI/UX
- 🎨 Animations and interactive elements
- 🌐 Cross-browser compatibility

---

## 💻 Tech Stack

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript (Vanilla)**
